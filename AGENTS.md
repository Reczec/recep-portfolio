# Recep Portfolio

Static site (plain HTML/CSS/JS) in `docs/`. No build step.

## Local development

- Run `python -m http.server 3036 --directory docs` and open `http://localhost:3036`.
- Port 3000 belongs to an unrelated AI Job Automation project. Never inspect or interact with `localhost:3000` while working here.
- German texts live in `docs/index.html`, English texts in `docs/app.js` (`EN` object, same keys as `data-i18n`).
- Only state facts that appear in the user's CVs; see `PRODUCT.md`.
